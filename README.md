# THE COFFEE MILK

南国キッチンを舞台に、見本の色に近いコーヒー牛乳をできるだけたっぷり作る5ラウンド制スコアアタックゲームです。

## 遊び方

- COFFEE / MILK ボタンを長押しして注ぎます。
- それぞれの材料ボタンは1ラウンドにつき1回しか使えません。指やマウスを離した時点で使用済みになります。
- 見本色は毎ラウンド、コーヒー比率10〜90%からランダムで決まります。
- スコアは「色の一致度 × 量」の掛け算です（各0〜100 → 最大10,000点/ラウンド）。
- 色・量どちらも非線形評価です。
- 容量を少しでも超えるとそのラウンドは0点です。
- 全5ラウンドの合計が最終スコアです。

## ラウンド

1. ビーカー（目盛りあり）
2. ストレートグラス
3. 背の高いグラス
4. カクテルグラス
5. 中身が見えないストレートグラス（残量メーターも隠れます）

## BGM / SE

Web Audio APIでリアルタイム生成しているため、音声ファイルは不要です。ブラウザの自動再生制限に対応し、STARTまたは最初の操作後に音が始まります。

## GitHub Pagesで公開

1. このフォルダの `index.html` / `style.css` / `script.js` をGitHubリポジトリ直下に置く
2. GitHubの `Settings` → `Pages`
3. `Build and deployment` の Source を `Deploy from a branch`
4. Branch を `main`、folderを `/ (root)` にして保存

外部ライブラリ・CDN・画像素材は使っていません。
