# THE COFFEE MILK

GitHub Pages でそのまま動く、5ラウンド制のコーヒー牛乳スコアアタックゲームです。

## 遊び方
- 毎ラウンド、TARGET の色に近いコーヒー牛乳を作ります。
- COFFEE / MILK はそれぞれ1回だけ使用できます。
- ボタンを押している間だけ注がれ、離すとそのボタンは使用済みになります。
- 色の近さ（0〜100）× 量（0〜100）がラウンド得点です。
- 得点は非線形で、色は完全一致付近、量は満杯付近ほどシビアになります。
- 1滴でも容量を超えると、そのラウンドは 0 点です。
- 5ラウンド合計、最大 50,000 点。

## ラウンド
1. BEAKER — 見やすい目盛り付き
2. STRAIGHT GLASS — 目盛りなし
3. TALL GLASS — 細長いハイボール型
4. COCKTAIL GLASS — 高さと容量感覚がズレる形
5. BLIND GLASS — 中身が見えない不透明グラス

FINAL は液面が見えません。注いでいる音は満杯に近づくほど連続的に高くなり、溢れる直前ではかなり高音になります。BGM は注いでいる間だけ止まり、音を判断材料にしやすくしています。

## 音
BGM / SE は Web Audio API で生成しているため、音声ファイルは不要です。ブラウザの自動再生制限に対応するため、START 操作後に音声が開始します。
